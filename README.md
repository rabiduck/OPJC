# Old Priory Judo Club website

Static promotional website for Old Priory Judo Club, York.

## Hosting
Designed to deploy directly to Cloudflare Pages from the `main` branch.

- Framework preset: None
- Build command: leave blank
- Build output directory: `/` (repository root)

## Status
Prototype / pre-launch.

Before public launch, confirm:
- Venue name and full address
- Contact email / enquiry route
- Which class is intended for which age or experience group
- Pricing after the free trial
- Safeguarding and privacy links
- Final club and Bushido logo artwork
- Approved club photography

## Deployment
Any commit to `main` can be configured to trigger a new Cloudflare Pages deployment.
